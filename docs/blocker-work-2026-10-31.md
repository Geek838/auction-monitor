# Blocker work — 31 October 2026

This increment addresses parts of the purchase-cost flow and investigates the two main remaining evidence gates. It does not constitute Auction Intelligence 1.0.

- **Official currency conversion:** the NBG dated feed linked by its public UI is requested for the Georgia calendar date, with bounded HTTPS and no redirects. A real API request returned 100 USD = 259.92 GEL at the 2.5992 rate effective 31 October 2026. A documented Sunday query returned a prior effective day, which remains labeled. Intermittent source failures remain possible and never produce a fallback rate.
- **Auction fees:** `/auction-fees` uses an explicitly requested, consented public third-party no-key service. A real synthetic 5,000 USD Copart request returned an estimated 1,030 USD fee and 6,030 USD bid-plus-fee total. This is undated, unverified, non-official and does not populate the budget. Commercial production rights, fee schedules and accuracy remain unestablished; see [source research](research/auction-fee-api-2026-10-31.md).
- **Georgia excise:** the supported component now includes left-hand-drive hybrids aged 0–6 and petrol/diesel cars with right or converted steering. Rates are supported by the Tax Code and actual official calculator examples; unsupported combinations are withheld. Remaining duties and fees are not calculated. See [evidence](georgia-excise-extension-2026-10-31.md).
- **Auction access:** [Apibara's documented candidate](research/apibara-feasibility-2026-10-31.md) explicitly lists a Copart/IAAI URL endpoint and advertises 100 no-card free requests monthly. A key/account is required, redistribution requires agreement, photo sublicensing and inference rights are unresolved, and its contract alone does not corroborate IAAI page-to-stock identity. No credential, source record, agreement or live-match validation exists; it is not activated. The provider inquiry in that document is prepared and unsent.
- **Vehicle-image quality:** [actual real-vehicle tests](research/local-vision-real-vehicle-2026-10-31.md) failed: the original Thinking model exhausted its output budget or timed out; the separate Instruct model generated truncated JSON, then an experimental prompt produced an incorrect image ID and unsafe/contradictory claims. The application withheld every result. The experimental prompt was reverted, a narrow wording guard and clearer truncated-output failure were added, and the prior model identification was corrected. One photograph cannot establish safety, precision, recall or repair-cost accuracy; this blocker remains open.
- **Repair prices:** [official Georgian fleet procurement evidence](research/georgia-repair-price-source-2026-10-31.md) includes actual itemized transactions, but vehicle compatibility, VAT and transferability to consumer repairs must be established before it can support the application's estimates. No fabricated retail quote has been added.

The final combined backend/tool suite passed **750 tests**. Targeted desktop/mobile browser checks passed for exchange, excise and auction fees (**28 checks**) and local inspection (**8 checks**). Browser fee checks use labeled response doubles; real external smoke requests are reported separately. TypeScript and the production build passed. The Windows launcher parsed and its loopback preflight was checked in PowerShell on Linux; full native Windows execution was not verified. No paid API, auction-site scraping, provider account or outreach was used.
