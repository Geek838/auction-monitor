# Auction Fees Calculator public API — 31 October 2026

Ordinary bounded HTTPS reads and one synthetic documented API request; no credentials, user vehicle data, purchases, accounts, supplier messages, Copart/IAAI scraping or access-control bypass.

The provider's [public API documentation](https://docs.auctionfeescalculator.com/) explicitly describes the API as free and requiring no API key. It documents a JSON `POST https://api.auctionfeescalculator.com`, supports Copart/IAAI fee estimates for bid/payment/vehicle types and optional inland towing, and says rate limiting may return HTTP 429. The [calculator website](https://www.auctionfeescalculator.com/) says its Copart calculation was updated September 2026, but that website statement is not a dated certification for a particular API response or fee schedule.

An actual no-redirect POST on 31 October used synthetic input `{"bidAmount":5000,"auction":"copart","bidType":"online","bidPay":"secured","bidVehicle":"standard","volume":"low"}`. It returned HTTP **201**, although its documentation describes HTTP 200, with `{"quote":{"bidAmount":5000,"auctionFees":{"auctionFee":1030,"totalAmount":6030}},"towing":null}`. No source timestamp, fee schedule version, validity period, itemized fee categories or official-auction provenance were supplied in that response. The result has not been independently verified against an applicable current official schedule; a mathematical total alone does not establish accurate fees. No towing quote was requested.

The linked [privacy policy](https://www.auctionfeescalculator.com/privacy-policy) discusses personal information, but the inspected public materials do not establish a commercial integration/data-use licence, endpoint SLA, retention rights, or a guarantee that all use is free of future charges. A single guessed `/terms` route returned 404; that does not prove a separate agreement does not exist. The public no-key example establishes a useful technical research lead, not permission for unlimited production reuse or proof of source accuracy.

**Implementation decision:** A local experimental integration allows an explicit user-consented request for an attributed, undated, unverified third-party estimate. It sends only the hypothetical bid and selected auction, bidding, payment, buyer/vehicle and volume options; no VIN, photo, listing URL or towing location is transmitted. It does not automatically populate the budget, mark a fee schedule complete, or establish a bid ceiling. The documented API is free to use without a key; its public materials do not establish a contractual guarantee against future charges. Before a public commercial deployment, establish applicable product-use terms, current official schedule sources and freshness, actual response/error contract, request limits and an independently verified comparison across relevant fee boundaries.
