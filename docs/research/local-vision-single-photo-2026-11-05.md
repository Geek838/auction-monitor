# Single-photo local-model engineering test — 5 November 2026

The `single-image-observation-v1` profile was exercised through the actual FastAPI local-inspection endpoint and loopback Ollama, using `qwen3-vl:2b-instruct` with the unchanged `local-inspection-v1` report schema. It is an experimental single-photo profile, not an independently reviewed accuracy benchmark or a buyer-ready inspection.

The source was [Altima-Accident.jpg](https://commons.wikimedia.org/wiki/File:Altima-Accident.jpg), by [Ryanandlenny](https://commons.wikimedia.org/wiki/User:Ryanandlenny), under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The image was resized and re-encoded; no image bytes are committed. Original SHA-256: `7e1e5f9098aad127f005086cf98f6627e1348d65508c517314f1f08b8adb4653`. The single 768 × 512 browser-prepared input SHA-256 was `96ae2fdd1e32b29a6fa7d49f48f8d014f0d214515f71497430e003ee3a925b26`; the backend's separately re-encoded inference bytes hashed to `0c8f4aaeb1265473ee01e1923c8925b969e86fa4b7920057b482bfc8b5070d0b`.

The model digest was `afc393e3572c07db0bc84aa460d928a16c75f3fbb9ca9e0dccc4fbd2dafb573e`. Ollama ran on loopback with cloud features disabled. The model received only that one image; it did not receive the fixture URL, the image label or an evidence ID. The model returns a compact strict schema without image IDs; after validation, the API binds any observation to the sole image actually sent and applies the existing full finding/wording validation. Other tags and multi-image requests continue to use the existing profile.

The actual request completed in **43.27 seconds**, using 89 output tokens, with one observation describing damage to the front bumper. Major front-bumper damage is visible in the source image. The wording “left side” is ambiguous and “large dent” was not independently verified. All six physical checks remained UNKNOWN, and the report explicitly says it can omit other damage. No expert inspection, invoice or ground-truth annotations were available. The Copart URL in the request was a fixture parser input and is **not** associated with the pictured vehicle.

This single result establishes neither model precision nor recall, safety, hidden-condition accuracy, repair-cost accuracy, or reliability on other images and sizes. It does not verify auction identity. Previous real-vehicle failures, including the Thinking-tag mismatch, timeouts, invented image ID and unsafe advice in another experimental prompt, are retained in [the earlier investigation](local-vision-real-vehicle-2026-10-31.md). The model output remains experimental and unreviewed; a qualified, independently reviewed vehicle cohort is still necessary.
