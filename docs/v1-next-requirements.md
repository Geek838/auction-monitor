## Official NBG evidence and implementation rules

Ordinary unauthenticated HTTPS reads on 30 October 2026 retrieved the following through Python `urllib.request.urlopen` with its default redirect handling. These are research reads, not proof that the application's stricter no-redirect transport can retrieve the feed. The full raw response was not retained; observed field excerpts below come from the research tool output and must not be relabelled as an exact saved-response artifact.

- [Official exchange-rate page](https://nbg.gov.ge/en/monetary-policy/currency), HTTP 200, 391,501 bytes on the first read. It visibly offers **JSON** and **RSS** and states: “The official exchange rate is an indicative rate and its use is not obligatory except for instances set by the relevant legal requirements.” A later repeated page read returned HTTP 403; no access check was bypassed.
- [Public JSON feed](https://nbg.gov.ge/gw/api/ct/monetarypolicy/currencies/en/json), HTTP 200, 8,728 bytes. A top-level array contains an effective-date group and currency records. The USD row had `quantity: 1`, `rate: 2.5959`, `rateFormated: "2.5959"`, `date: "2026-10-29T17:01:14.556Z"`, and `validFromDate: "2026-10-30T00:00:00.000Z"`; the group `date` matched that effective date. These values are observed research evidence, never an application fallback/default.
- [User Policy](https://nbg.gov.ge/en/user-policy), HTTP 200. Its English content states that personal-data processing follows Georgian personal-data law. No explicit API SLA, redistribution contract or blanket commercial-photo/model-use licence was established by this policy. A publicly linked statistical feed supports the narrow attributed reference-rate operation; it is not permission for unrelated content reuse.

Use the JSON numeric representation with decimal-aware parsing rather than introducing a binary float. Ignore unrelated currencies after validating the USD binding; duplicate USD rows are an error. A currency's quoted GEL amount applies to its `quantity` units. Store source time semantics separately rather than calling every timestamp “rate date.” The dated query was verified from the official site's own link; callers cannot select arbitrary historical dates. If a returned record is future-effective, report that limitation.

At the earlier implementation smoke the strict production transport encountered HTTP 403 or self-redirect HTTP 307 and returned `UNAVAILABLE`. On 31 October 2026 (Georgia calendar), strict no-redirect transport successfully retrieved the official feed and the real API converted USD 100.00 to GEL 259.92 at 2.5992. The official currency page itself linked `currencies/en/json/?date=2026-10-31`; the application now requests the internally generated current Georgia date over HTTPS rather than taking a user-supplied date or URL. A dated Sunday request for 25 October returned the previous effective date, 24 October. The effective date and age are never replaced with the requested date, and a midnight boundary cannot make a future response for an earlier requested day usable. Prior denial/redirect behavior still demonstrates intermittent availability. No access control was bypassed. RSS remains unvalidated and is not a fallback.

Use the rate as indicative USD→GEL multiplication or GEL→USD division, with decimal arithmetic and final HALF_UP cent rounding. Do not independently round the unit rate to cents before multiplying. Source publication changes and upstream denial must remain ordinary availability failures. No account, card, key or purchase was required for these research reads.

## Georgian tax subset assessment

**Subsequent 30 October validation:** Seven actual official RS calculator cases and the primary Georgian Article 188 clauses now support a frozen [narrow excise-component requirement](georgia-excise-component-requirements.md). Its explicit current-2026 planning window and supported vehicle facts replace the earlier prerequisite-only assessment below for excise alone. Full clearance and budget-category completion remain outside this scope.

The PO reread the [official English Tax Code publication 247](https://matsne.gov.ge/en/document/view/1043717?publication=247) on 30 October. The relevant excise clauses remain observable: Article 188(12–18) includes age 0–6 versus over-six engine-displacement rates, hybrid and steering adjustments, electric cases and production-year-based age. This confirms that sourced deterministic work is feasible; the [earlier evidence](georgia-cost-evidence.md) must not be represented as “no official rules available.”

A limited **statutory excise component** could be developed only with explicit supported 8703 classification/procedure and exclusions, production/declaration year, displacement, powertrain/steering inputs, dated rule applicability and independently validated examples. It would still be one component, not total clearance. Decoded VIN model year is insufficient. Re-export refunds must remain separate from cash required at import. The current increment does not have official calculator outcome validation, complete exemptions/VAT/classification/service-fee coverage or primary Georgian/English equivalence review. Therefore keep existing clearance and registration amounts sourced/user-declared and keep automatic total-tax output withheld. This is the team's research/validation work, not a task assigned to the client.
