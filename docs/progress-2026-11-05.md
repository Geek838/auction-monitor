# Buyer-flow progress — 5 November 2026

This increment does not constitute release 1.0. The source and identity limitations in [readiness](v1-release-readiness.md) still apply.

- The homepage now places the listing input first and uses compact navigation. Mock/provider status and unverified evidence remain visible; source details can be expanded. A 390-pixel mobile viewport was inspected without horizontal overflow.
- The Apibara adapter now rejects non-ASCII VIN characters before uppercase normalization, preventing Unicode expansion from manufacturing a valid-looking VIN. Its 21 focused tests passed. No key was available for an authenticated provider call; IAAI page-to-stock mapping remains unresolved.
- Left-hand-drive hybrid excise calculations now cover ages 7–30 at the ordinary rate, in addition to the existing reduced rate through age six. The [evidence](georgia-excise-extension-2026-10-31.md) includes an earlier official calculator case and a 5 November comparison of Articles 188 and 197 across Georgian Tax Code publications 247 and 248. That comparison is not a review of all exemptions or an official customs assessment. Import duty remains withheld.
- The optional `qwen3-vl:2b-instruct` single-photo path binds at most one observation to the only input image in application code. A real FastAPI → local model test on a licensed 768 × 512 damaged-vehicle photo completed in 43.27 seconds. It returned a plausible bumper observation, but some wording was uncertain. This is one engineering example, not a benchmark or proof of vehicle condition; all safety-critical checks remain unknown. See the [test record](research/local-vision-single-photo-2026-11-05.md) for model digest, image attribution and limitations. Earlier failed tests remain documented.

The backend/tool suite passed **778 tests**; **54 desktop/mobile browser checks** passed for the resolver, provider interface, workflow, excise and local-inspection paths. TypeScript and the production build passed. Browser consumer doubles do not constitute a live provider connection. Native Windows execution of the updated local-model launcher was not verified.

The original purchase flow still needs live authorized source access, verified matching/IAAI mapping, independently reviewed damage quality, and sufficiently supported Georgian repair and landed-cost evidence. No paid API, invented prices, auction scraping or image-quality claim was introduced.
